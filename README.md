# CybersecurityTestingSupport

Android 資安測試輔助工具：遮罩（不透／穿透）、延遲／立即截圖與錄影、功能浮窗。

用來測對方 App 的遮蔽偵測、`FLAG_SECURE` 等防護。

## 功能

- **遮罩**：全畫面／部分 × 不透／穿透；點標籤可關閉
- **擷取**：MediaProjection session；主畫面 5 秒延遲、浮窗立即執行
- **浮窗**：圖標「測」展開操作；貼邊、收合／關閉
- **權限**：Overlay、通知、螢幕擷取分區管理

## 建置

用 Android Studio 開啟專案，執行 `app` module。

檔案輸出：`Pictures/CybersecurityTestingSupport`、`Movies/CybersecurityTestingSupport`
